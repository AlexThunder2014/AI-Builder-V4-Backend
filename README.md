# AI Builder V4 Backend

Das Backend ist der KI-Server für AI Builder V4.

## Funktionen

- KI-Chat
- Programmierhilfe
- Code-Generierung
- Projektkontext
- Bildgenerierung
- Health-Check
- CORS
- Umgebungsvariablen
- API-Key bleibt auf dem Server

## Installation

Node.js installieren.

Danach im Backend-Ordner:

```bash
npm install
